# Hostel Management Frontend

React + Vite frontend for a hostel student-record management system.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Copy `.env.example` to `.env` and set `VITE_API_URL`:
   - Local backend: `http://localhost:5000/api`
   - Deployed backend: `https://YOUR-BACKEND-DOMAIN/api`
5. Run `npm run dev`.

## Build

Run `npm run build`. Vite creates the production files in `dist/`.

## Features

- View and search hostel student records
- Add and edit student details
- Delete student records
- Track paid / pending hostel fee status
